# eval_pose_candidates.json

Generated by: `playground/graph_models/models/visualize_eval_loc_candidates.py`

This JSON stores candidate camera locations/poses for each scene, plus the
ground-truth pose (from the frame JSON) and the final predicted pose.

## Top-level structure

```json
{
  "scenes": [ ... ],
  "skipped": [ ... ],
  "args": { ... }
}
```

### `scenes` (list)

Each entry corresponds to a single scene/frame.

Fields:
- `scene_id` (string): 3RScan scene ID.
- `frame_id` (string): frame name or image index.
- `frame_path` (string): path to the source frame JSON.
- `description` (string|null): caption text in the frame JSON.
- `timestamp` (string|null): timestamp from the frame JSON (if present).
- `visible_objects_count` (int): number of visible objects in the frame JSON.
- `matched_object_ids` (list[int]): 3D object IDs selected by top-K cosine match.
- `matched_object_count` (int): count of `matched_object_ids`.
- `grid` (object):
  - `step` (float): XY grid spacing in meters.
  - `eye_height` (float): camera height added to the mesh Z min.
  - `points` (int): total grid points sampled.
- `grid_max_visible_count` (int): max matched-object visibility count on grid.
- `grid_max_visible_point_count` (int): number of grid points that reach the max.
- `grid_point_candidates` (list): top-N grid points ranked by visibility count.
  - `position` (list[float]): XYZ in world coordinates (meters).
  - `visible_count` (int): number of matched objects visible from this grid point.
  - `prob` (float): visibility count normalized over the grid.
- `fov_pose_candidates` (list): top-N pose candidates with directions, derived
  from an FOV window (may be empty if FOV aggregation is unavailable).
  - `position` (list[float]): XYZ in world coordinates (meters).
  - `direction` (list[float]|null): unit vector in world coordinates.
  - `visible_count` (int): max objects visible within the FOV window.
- `gt_pose` (object):
  - `position` (list[float]): GT camera center in world coordinates.
  - `direction` (list[float]|null): unit vector of GT forward direction.
  - `scene_pose` (list[list[float]]): 4x4 camera-to-world matrix from frame JSON.
- `predicted_pose` (object):
  - `position` (list[float]): predicted camera center in world coordinates.
  - `direction` (list[float]|null): predicted viewing direction (if available).
  - `source` (string): prediction source, e.g. `grid_visibility:weighted`
    or `arrow_fov:weighted`.

Notes:
- All positions and directions are in the world coordinate frame of the scene.
- The forward direction is computed as `R * [0, 0, 1]` from the 4x4 `scene_pose`.

### `skipped` (list)

Entries for scenes that were skipped during processing.

Fields:
- `scene_id` (string)
- `reason` (string)

### `args` (object)

CLI arguments captured for reproducibility.

Fields:
- `root`, `graphs`, `query_root`
- `frame_policy`, `frame_index`, `seed`
- `top_k`, `grid_step`, `eye_height`
- `prediction_strategy`, `cluster_bandwidth`, `max_cluster_points`
- `h_fov_deg`, `v_fov_deg`, `arrow_stride`
- `top_candidates`, `top_pose_candidates`
